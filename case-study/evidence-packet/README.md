# HarborPay Demo evidence packet

**Synthetic training artifacts.** Every organization, document, date, control statement, and result in this packet is invented for a portfolio exercise. These are not vendor evidence, audit reports, certification records, or legal advice. The packet is deliberately designed to contain both useful information and material limitations so a reviewer must analyze it rather than count documents.

Assessment: `HPD-2026-001` · payroll processing SaaS · review date 16 November 2026. Read each exhibit alongside [`../data.json`](../data.json); the structured evidence fields are lab fixtures, while these readable exhibits provide the reasoning context. E02-v2 and E03-v2 are explicitly simulated revisions, not proof of real remediation.
